   This is my action game Finished project, built from scratch in Unreal Engine 5 using the
    Gameplay Ability System (GAS) and a Gameplay Tag-driven design.The main goal for this project was to
    familiarize myself with Unreal GAS.
    I tried to follow best practices throughout the project, 
    which resulted in several systems that work independently of one another,
     some of which are even independent of specific assets.
    Here are a few of the features this project includes:
    Three types of enemies, each with a different AI.
    Three special abilities for the player character.
    One special ability for enemies.
    Asynchronous loading wherever needed to provide a smooth experience.
    Directional hit reactions.
    And more!
